# Fallen X
Overview
This repository contains the Unity project developed by Team 2 for the Game 290 course during Spring 2025.
Fallen X is a third-person stealth adventure game where the protagonist Pip, has to find and rescue his lost crewmates after crash landing on a mysterious and unknown planet... Earth. 
Players will take on the role of Pip, the young inexperienced traveler who may be small in size but is willing to do what it takes to save his crew. 
Pip will navigate through plains, forests, and laboratories in such of their crewmates. The player will have to be smart and discreet as Pip isn’t a strong alien so stealth is the only option. 
Hide in bushes, walk slowly, and silently navigate through the multiple layers of each level as you search for keys,journals, and air. Find your crew members, steal a ship, and avoid the humans at all costs in this alien adventure.

The vic-edits branch includes the latest version of the game. 

The project is structured as a full Unity workspace, including assets, scripts, scenes, prefabs, and project settings required for collaborative development.
Using Unity version 2022.3.43f1
